# Qualitative comparison inputs

These four images are the exact source images used by the public Talk2DINO
qualitative comparison. They are included only to run ASFD+VADD on identical
visual content, so the paper grid compares methods image by image.

Source: <https://github.com/lorebianchi98/Talk2DINO/tree/main/assets/qualitatives>

The paper compositor uses the corresponding released ground-truth and method
visualizations for FreeDA, ProxyCLIP, CLIP-DINOiser, and Talk2DINO. It never
uses generated or manually painted segmentation masks.
